# Fantasy Repo Context

Fantasy is a local-first dynasty fantasy football intelligence app.

## Read When

| Task evidence | Read |
| --- | --- |
| Fantasy advice involving a player, roster, trade, picks, waivers, lineup, standings, or team direction | `fantasy-decisions.md` |
| Running verification, install, lint, tests, or builds | `commands.md` |
| External-facing market or audience research | `market.md` when present |
| CLI/API/tool publishing or command-surface work | `printing-press.md` when present |

Keep `AGENTS.md` as the always-loaded router. Put stable repo detail here only when it helps agents avoid rediscovery.
