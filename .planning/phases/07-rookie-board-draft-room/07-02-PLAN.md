    Create `backend/src/fantasy/rookie/rookie_engine.py` following the engine class pattern from `picks/pick_engine.py` and `trade/trade_engine.py`.

    ```python
    class RookieEngine:
        def __init__(self, conn: duckdb.DuckDBPyConnection):
            self._conn = conn
            self._repo = RookieRepo(conn)
    ```

    **Public methods:**

    1. `compute_board(self, league_id: str) -> RookieBoardResult`:
       - Calls `self._repo.get_league_settings(league_id)` to get format flags
       - Calls `self._repo.get_available_rookies(league_id)` to get raw player data
       - For each player: calls `_score_rookie(player_dict, league_settings)` to get composite score
       - Assigns archetype via `_assign_archetype(player_dict)`
       - Assigns risk band via `_assign_risk_band(player_dict)`
       - Sorts by composite_score descending
       - Calls `_assign_tiers(sorted_players)` to bucket into tiers
       - Computes `available_probability_by_slot` per player using `slot_availability_probability()`
       - Calls `_compute_class_strength(sorted_players)` for the signal
       - Calls `_format_label(league_settings)` for the format badge string
       - Saves to cache via `self._repo.save_board_cache()`
       - Returns `RookieBoardResult`

    2. `compute_class_strength(self, league_id: str) -> float`:
       - Calls `compute_board()` and returns `board.class_strength_signal`

    **Private methods:**

    3. `_score_rookie(self, player: dict, league_settings: dict) -> float`:
       - Base score from ADP position (higher ADP = higher base score; formula: `100 - (adp * 2)` clamped to [0, 100])
       - Format adjustments:
         - If `league_settings["superflex"]` is True and player position is "QB": multiply score by 1.3
         - If `league_settings["ppr"]` == 1.0 and position in ("WR", "TE"): multiply score by 1.15
         - If `league_settings["ppr"]` == 0.5 and position in ("WR", "TE"): multiply score by 1.07
         - If `league_settings["ppr"]` == 0.0 and position == "RB": multiply score by 1.10
         - If `league_settings["tep"]` is True and position == "TE": multiply score by 1.20
       - Return the adjusted composite score

    4. `_assign_tiers(self, players: list[RookiePlayer]) -> list[RookieTier]`:
       - Gap-based tier assignment per RESEARCH.md algorithm
       - Walk sorted scores, create new tier when gap between consecutive scores >= GAP_THRESHOLD
       - Cap at MAX_TIER_COUNT
       - Use TIER_LABELS[tier_number] for the label string
       - Return list of RookieTier objects

    5. `_assign_archetype(self, player: dict) -> str`:
       - If player position exists in ARCHETYPE_LABELS and sufficient profile data exists: select the most fitting archetype from the vocabulary based on available metadata (e.g., team context, draft capital)
       - If data is insufficient: return ARCHETYPE_FALLBACK_TEMPLATE.format(position=player["position"])
       - Phase 7 uses a simplified rule-based approach; Phase 8 replaces with backtested model

    6. `_assign_risk_band(self, player: dict) -> str`:
       - HIGH risk signals: age > 23 for non-QB, undrafted or late-round NFL draft capital, injury history flags
       - LOW risk signals: top-15 NFL draft capital, high college production (market share signals from stats), multiple years of production
       - MODERATE: everything else (the default)
       - Returns RISK_BAND_LOW, RISK_BAND_MODERATE, or RISK_BAND_HIGH

    7. `_compute_class_strength(self, players: list[RookiePlayer]) -> float`:
       - Per RESEARCH.md formula: count Tier 1 and Tier 2 players, compute delta from baselines, weight with CLASS_TIER1_WEIGHT and CLASS_TIER2_WEIGHT, clamp to [-1.0, 1.0]
       - Returns 0.0 for empty player list

    8. `slot_availability_probability(player_rank: int, slot: int) -> float` (module-level function):
       - If slot < player_rank: return 0.05
       - gap = slot - player_rank
       - return min(0.95, 0.50 + gap * SLOT_AVAILABILITY_SLOPE)

    9. `_format_label(self, league_settings: dict) -> str`:
       - Build parts list: if superflex, append "Superflex"; if tep, append "TEP"
       - if ppr == 1.0: append "PPR"; elif ppr == 0.5: append "Half PPR"; else: append "Standard"
       - Return " · ".join(parts)

    **Tests** in `test_rookie_engine.py`: Write unit tests covering all behaviors listed above. Use mock/patch for RookieRepo methods to isolate engine logic. The test file should have at least 15 test functions.
