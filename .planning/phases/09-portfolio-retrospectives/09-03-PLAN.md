**Create `backend/src/fantasy/portfolio/retro_engine.py`:**

Class `RetroEngine` with `__init__(self, conn)`:

**Method `grade_direction_labels(self, season: str) -> dict`:**
1. Query `team_directions` for all direction label assignments in the given season: `SELECT league_id, roster_id, primary_label, confidence FROM team_directions WHERE season = ?`
2. Query `standings` for actual season outcomes: `SELECT league_id, roster_id, wins, losses, points_for FROM standings WHERE season = ?`
3. For each direction label, grade against outcome:
   - "True Contender" / "Fragile Contender" -> expected top-half win rate (wins > total_games/2)
   - "Hard Rebuild" / "One-Year Punt" -> expected bottom-half win rate
   - "Productive Struggle" / "Retool" -> expected middle third
   - "Fringe Playoff" -> expected near .500
   - "Elite Value Accumulation" -> flexible (no strict win-rate mapping)
4. Compute grades: for each label category, `correct_count / total_count` = accuracy
5. Return dict with per-label accuracy and overall accuracy
6. Save via `PortfolioRepo(self.conn).save_retrospective_run(run_type="direction_labels", season=season, grades_json=grades_dict)`

**Method `grade_prospect_tiers(self, season: str) -> dict`:**
1. Guard: check if `prospect_model_outputs` table exists using `SELECT table_name FROM information_schema.tables WHERE table_name = 'prospect_model_outputs'`. If not found, return `{"status": "skipped", "reason": "prospect_model_outputs table does not exist (Phase 8 not run)"}` and save that as the grades_json.
2. If table exists: query `SELECT player_id, predicted_tier, predicted_bucket FROM prospect_model_outputs WHERE draft_season = ?`
3. Query `player_stats_weekly` for actual NFL outcomes for those players (aggregate stats per player for seasons after draft)
4. Apply Phase 8 hit-rate definitions to classify actual outcomes as hit/mediocre/bust
5. Compare predicted bucket vs actual outcome: compute accuracy per position and per tier
6. Return dict with per-position accuracy, per-tier accuracy, overall accuracy
7. Save via `PortfolioRepo(self.conn).save_retrospective_run(run_type="prospect_tiers", season=season, grades_json=grades_dict)`

**Create `backend/src/fantasy/routers/portfolio.py`:**

```python
from fastapi import APIRouter, Depends
import duckdb
from fantasy.routers.deps import get_conn
from fantasy.portfolio.portfolio_engine import PortfolioEngine
from fantasy.portfolio.portfolio_repo import PortfolioRepo
from fantasy.portfolio.models import ExposureRow, CorrelatedRiskRow, RecalibrationHealth

router = APIRouter(prefix="/portfolio", tags=["portfolio"])

@router.get("/exposure")
def get_exposure(
    conn: duckdb.DuckDBPyConnection = Depends(get_conn),
) -> dict:
    engine = PortfolioEngine(conn)
    exposure = engine.compute_exposure()
    correlated_risk = engine.compute_correlated_risk()
    return {
        "exposure": [row.model_dump() for row in exposure],
        "correlated_risk": [row.model_dump() for row in correlated_risk],
    }

@router.get("/health", response_model=RecalibrationHealth)
def get_health(
    conn: duckdb.DuckDBPyConnection = Depends(get_conn),
) -> RecalibrationHealth:
    repo = PortfolioRepo(conn)
    last_at = repo.get_last_recalibration()
    return RecalibrationHealth(last_recalibrated_at=last_at)
```

The `/portfolio/exposure` endpoint returns both exposure rows and correlated risk rows in a single payload to minimize frontend API calls (one fetch populates both the matrix and the correlated risk section). The `/portfolio/health` endpoint returns the recalibration timestamp (or null if never recalibrated) per D-14.
