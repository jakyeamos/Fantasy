Props: `{ leagueId: string, snapshotId: number, rosterId: number, anchorLabel: string }`

**Client-side sort function** (implement inline or as helper):
```typescript
function sortDiffRows(rows: DiffRow[]): DiffRow[] {
  return [...rows].sort((a, b) => {
    if (a.field_type === "departed" && b.field_type !== "departed") return 1
    if (b.field_type === "departed" && a.field_type !== "departed") return -1
    if (a.field_type === "added" && b.field_type !== "added") return 1
    if (b.field_type === "added" && a.field_type !== "added") return -1
    if (a.field_type === "direction_label" && b.field_type !== "direction_label") return 1
    if (b.field_type === "direction_label" && a.field_type !== "direction_label") return -1
    return Math.abs(b.delta ?? 0) - Math.abs(a.delta ?? 0)
  })
}
```

Structure:
- Section label: `<p className="text-sm text-muted-foreground">What changed since {anchorLabel}</p>` (per UI-SPEC copywriting)
- Diff rows container: `<div className="flex flex-col gap-2 mt-4">`
- Each DiffRow: `<div className="flex items-center justify-between py-1">`
  - Left: `<span className="text-xs text-muted-foreground">{row.field}</span>`
  - Right: `<span className={colorClass}>{row.display_string}</span>` where colorClass depends on field_type and delta sign:
    - Positive numeric delta: `text-green-700 dark:text-green-300`
    - Negative numeric delta: `text-red-600 dark:text-red-400`
    - direction_label: `text-foreground`
    - departed: `text-muted-foreground italic`
    - added: `text-green-700 dark:text-green-300`
    - No delta (neutral): `text-muted-foreground`

States:
- Loading: 5x `<Skeleton className="h-6 w-full rounded" />`
- Success: render sorted diff rows
- Empty: "No changes detected since this snapshot." — `text-sm text-muted-foreground text-center`
- Error: "Snapshot comparison unavailable. Check that the backend is running, then refresh."
