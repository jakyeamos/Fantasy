Create `backend/src/fantasy/portfolio/snapshot_diff_engine.py` with class `SnapshotDiffEngine`:

**`__init__(self, conn)`:** Accepts DuckDB connection (same pattern as PortfolioRepo).

**Method `load_anchors(self, league_id: str) -> list[SnapshotAnchor]`:**

Three anchor types, merged and sorted by `snapshot_at` descending:

1. **Trade anchors:** Query `league_snapshots` JOIN `transactions` where `transactions.type = 'trade'` AND `transactions.status = 'complete'` AND timestamp proximity < 1 hour (`ABS(EPOCH(ls.snapshot_at) - EPOCH(t.created_at)) < 3600`). Label format: `"Trade - {Mon DD, YYYY}"` (e.g., "Trade - Feb 14, 2026"). Per D-04, use event-anchored labels, not raw dates.

2. **Roster change anchors:** Query `league_snapshots` where `snapshot_type = 'delta'`, parse `payload_json` to check `delta.changed_rosters` length >= `SNAPSHOT_ROSTER_CHANGE_THRESHOLD` (= 3 from constants). Label format: `"Roster change - {Mon DD, YYYY}"`. Use Python's `json.loads` on `payload_json` to extract `delta.changed_rosters`.

3. **Season checkpoint anchors:** Query `league_snapshots` where `snapshot_type = 'full'`, identify first and last snapshot per season. Label first as `"Season start - {Mon DD, YYYY}"`, last as `"Season end - {Mon DD, YYYY}"`.

Return all anchors as `list[SnapshotAnchor]` sorted by `snapshot_at` descending (most recent first). The `label` field is the pre-formatted string — frontend renders verbatim (per D-04, implementation note 4 in UI-SPEC).

**Method `compute_diff(self, league_id: str, snapshot_id: int, roster_id: int) -> list[DiffRow]`:**

1. Load historical snapshot: `SELECT payload_json FROM league_snapshots WHERE id = ? AND league_id = ?`. Parse JSON. Find the roster matching `roster_id` in `state.rosters[]`.

2. Load current state from live tables:
   - Direction label: `SELECT primary_label, confidence FROM team_directions WHERE league_id = ? AND roster_id = ? ORDER BY computed_at DESC LIMIT 1`
   - Scorecard sub-scores: `SELECT * FROM team_scorecards WHERE league_id = ? AND roster_id = ? ORDER BY computed_at DESC LIMIT 1`
   - Player values: `SELECT player_id, player_name, position, lens_market FROM player_values WHERE league_id = ? AND roster_id = ?`
   - Pick capital: try `from fantasy.picks.pick_engine import PickEngine` -> `compute_capital_score(league_id, roster_id)` with ImportError/Exception guard

3. Compute field-by-field deltas:

   - **Direction label:** Compare `historical_roster["direction"]["label"]` vs current `primary_label`. If changed, emit DiffRow with `field_type="direction_label"`, `display_string=f"{old_label} -> {new_label}"`, delta=None.

   - **Scorecard sub-scores:** For each of the 9 sub-scores (win_now, future_value, depth, pick_capital_score, flexibility, fragility, age_risk, liquidity, positional_insulation), compute `current - historical`. Only emit DiffRow if `abs(delta) >= 1.0`. `field_type="scorecard"`, `display_string` with arrow and magnitude.

   - **Player values (lens_market):** Match by `player_id`. For players in both current and snapshot: compute delta. Only emit if `abs(delta) >= 1.0`. For players in snapshot but not in current: emit `field_type="departed"`, check transactions table for trade vs drop to set departure type. Display: `"Traded (was {position})"` or `"Dropped (was {position})"`. For players in current but not in snapshot: emit `field_type="added"`, display: `"+ {player_name} added"`.

   - **Pick capital:** Historical `capital_score` from snapshot payload (added by Plan 09-01 patch). Current from PickEngine. Delta = current - historical. Emit if delta != 0. `field_type="pick_capital"`, `display_string=f"{'up' if delta > 0 else 'down'}{abs(delta):.0f} pts"` (using actual arrow chars).

4. Return `list[DiffRow]` — frontend sorts client-side by abs(delta) descending per UI-SPEC implementation note 5.

**Create `backend/src/fantasy/routers/snapshot_diff.py`:**

Follow the exact pattern from the existing picks router (or whichever router is most recent).

```python
from fastapi import APIRouter, Depends
import duckdb
from fantasy.routers.deps import get_conn
from fantasy.portfolio.snapshot_diff_engine import SnapshotDiffEngine
from fantasy.portfolio.models import SnapshotAnchor, DiffRow

router = APIRouter(prefix="/leagues", tags=["snapshot-diff"])

@router.get("/{league_id}/snapshot-anchors", response_model=list[SnapshotAnchor])
def get_snapshot_anchors(
    league_id: str,
    conn: duckdb.DuckDBPyConnection = Depends(get_conn),
) -> list[SnapshotAnchor]:
    engine = SnapshotDiffEngine(conn)
    return engine.load_anchors(league_id)

@router.get("/{league_id}/snapshot-diff", response_model=list[DiffRow])
def get_snapshot_diff(
    league_id: str,
    snapshot_id: int,
    roster_id: int,
    conn: duckdb.DuckDBPyConnection = Depends(get_conn),
) -> list[DiffRow]:
    engine = SnapshotDiffEngine(conn)
    return engine.compute_diff(league_id, snapshot_id, roster_id)
```

The `snapshot_id` and `roster_id` are query parameters on the diff endpoint. The frontend passes these from the selected anchor and the current user's roster.
