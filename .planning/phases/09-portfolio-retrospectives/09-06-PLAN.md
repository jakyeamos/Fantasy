**`ConcentrationAlertBanner.tsx`:**

Props: `{ leagueId: string; userRosterPlayerIds: string[] }`

Logic:
- Call `useQuery(portfolioExposureOptions())`
- Filter `rows` to players where `owned_in_leagues.length > 1` AND `player_id` is in `userRosterPlayerIds`
- If filtered list is empty or data is loading: render nothing (`null`)
- If league count for all filtered players is 1 after excluding the current league: render nothing (user only has one connected league with this player)

Render (when flagged players exist):
```
[!] Cross-league exposure — [n] player(s) on this roster are owned in other leagues:
  • [PlayerName] ([Position]) — [league_count] leagues  [badge]  [hedge_rec if present]
  ...
[View full exposure →]  (links to /portfolio)
```

Badge convention (matches Portfolio page ExposureMatrix badges):
- `league_count === 2`: amber badge "2 leagues"
- `league_count >= 3`: red badge "3+ leagues"

Use shadcn `Badge` with `variant="outline"` and inline color class. Use `Alert` component from shadcn for the outer container with a warning icon. Keep it compact — one line per player, no expand/collapse.
