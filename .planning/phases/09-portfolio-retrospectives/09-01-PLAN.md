**`models.py`:** Pydantic v2 models:
```python
from pydantic import BaseModel
from datetime import datetime

class ExposureRow(BaseModel):
    player_id: str
    full_name: str
    position: str
    team: str | None
    owned_in_leagues: list[str]  # league_ids
    league_count: int
    hedge_rec: str | None = None  # populated for 3+ leagues only

class CorrelatedRiskRow(BaseModel):
    nfl_team: str
    players: list[dict]  # [{player_id, full_name, league_id}]
    league_ids: list[str]
    risk_string: str  # verbatim display string

class SnapshotAnchor(BaseModel):
    snapshot_id: int
    snapshot_at: datetime
    anchor_type: str  # "trade" | "roster_change" | "season_start" | "season_end"
    label: str  # pre-formatted: "Trade - Feb 14, 2026"

class DiffRow(BaseModel):
    field: str  # "direction", "pick_capital", player_name, scorecard sub-score name
    field_type: str  # "direction_label" | "scorecard" | "player_value" | "pick_capital" | "departed" | "added"
    delta: float | None = None  # numeric delta; None for direction label changes
    old_value: str | None = None
    new_value: str | None = None
    display_string: str  # pre-formatted for frontend

class RetroGrade(BaseModel):
    run_type: str  # "direction_labels" | "prospect_tiers" | "full"
    season: str
    grades_json: dict  # grading results blob
    notes: str | None = None

class RecalibrationHealth(BaseModel):
    last_recalibrated_at: datetime | None = None
```

**`portfolio_repo.py`:** PortfolioRepo class with `__init__(self, conn)` accepting a DuckDB connection (same pattern as `PickRepo.__init__`):

Method `load_exposure_rows(self) -> list[ExposureRow]`:
- Query: UNNEST + FROM_JSON on `rosters.players` JSON field, JOIN `players` table for `full_name`, `position`, `team`
- GROUP BY `player_id` to get `league_count` and `owned_in_leagues` (LIST of DISTINCT league_id)
- ORDER BY `league_count DESC, full_name ASC`
- Return as list of ExposureRow (hedge_rec populated later by engine)

Method `load_correlated_risk_rows(self) -> list[CorrelatedRiskRow]`:
- From the same roster+player data, group by `(player.team, league_id)` pairs
- Filter: NFL team appears with players across >= CORRELATED_RISK_MIN_LEAGUES leagues AND >= CORRELATED_RISK_MIN_PLAYERS total players from that team across those leagues
- Return as list of CorrelatedRiskRow (risk_string populated later by engine)

Method `get_last_recalibration(self) -> datetime | None`:
- Query: `SELECT MAX(run_at) FROM retrospective_runs`
- Return datetime or None if no rows

Method `save_retrospective_run(self, run_type: str, season: str, grades_json: dict, notes: str | None = None) -> None`:
- INSERT into `retrospective_runs` table

**Patch SnapshotService (`snapshot_service.py`):**

In the `_build_league_state()` method, after the existing code that builds roster data (direction, player_values, etc.), add a `capital_score` field to each roster dict:

```python
# After existing roster dict construction, before returning:
capital_scores: dict[int, float] = {}
try:
    from fantasy.picks.pick_engine import PickEngine
    pick_engine = PickEngine(self.conn)
    for roster in rosters_data:
        roster_id = roster["roster_id"]
        capital_scores[roster_id] = pick_engine.compute_capital_score(
            league_id=league_id,
            roster_id=roster_id,
        )
except (ImportError, Exception):
    pass  # Phase 6 not available or engine error; capital_score omitted

# Then in each roster dict:
for roster in rosters_data:
    roster["capital_score"] = capital_scores.get(roster["roster_id"])
```

The try/except ImportError guard ensures this works even if Phase 6 is not yet available. The broader Exception catch prevents snapshot creation from failing if the pick engine errors.
