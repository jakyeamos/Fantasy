```python
from __future__ import annotations
from typing import Any
from pydantic import BaseModel, ConfigDict

class LeagueTaxiConfig(BaseModel):
    """Per-league taxi eligibility configuration (D-15). Follows LeagueDraftOrderRule pattern."""
    model_config = ConfigDict(frozen=False)
    taxi_slots: int
    taxi_years_eligible: int
    years_pro_cutoff: int

class LineupSlotScore(BaseModel):
    model_config = ConfigDict(frozen=False)
    position: str           # e.g. "QB", "RB", "WR", "TE", "FLEX", "SUPER_FLEX"
    player_id: str
    player_name: str
    starter_value: float    # this player's value proxy
    replacement_level: float  # weakest starter at this position league-wide (D-01, D-02)
    score: float            # starter_value - replacement_level, normalized 0-1

class LineupResult(BaseModel):
    model_config = ConfigDict(frozen=False)
    league_id: str
    roster_id: int
    computed_at: str | None = None
    slot_scores: list[LineupSlotScore]
    total_lineup_score: float        # sum of slot scores normalized
    title_window_label: str          # "Peak Window" | "Fading Window" | "Outside Window" (D-05)
    title_window_composite: float    # raw composite before label
    ceiling_score: float             # normalized within league
    stability_score: float           # normalized within league
    depth_score: float               # normalized within league

class HygieneSuggestion(BaseModel):
    """Single roster hygiene suggestion (D-10 through D-14)."""
    model_config = ConfigDict(frozen=False)
    action_type: str  # "consolidate" | "cut" | "stash" | "taxi"
    primary_player_ids: list[str]
    primary_player_names: list[str]
    target_player_id: str | None = None
    target_player_name: str | None = None
    counterparty_roster_id: int | None = None
    counterparty_name: str | None = None
    reasoning: str
    direction_fit_score: float  # 0-1; higher = more aligned

class HygieneResult(BaseModel):
    model_config = ConfigDict(frozen=False)
    league_id: str
    roster_id: int
    computed_at: str | None = None
    suggestions: list[HygieneSuggestion]

class TitleWindowResult(BaseModel):
    """Standalone title-window classification for API response (D-07)."""
    model_config = ConfigDict(frozen=False)
    league_id: str
    roster_id: int
    label: str         # "Peak Window" | "Fading Window" | "Outside Window"
    composite: float
    ceiling_score: float
    stability_score: float
    depth_score: float
```

**Taxi Config CRUD** (per D-15):
- `get_taxi_config(league_id: str) -> LeagueTaxiConfig | None`: SELECT from `league_taxi_configs` WHERE league_id; return None if not found.
- `save_taxi_config(league_id: str, config: LeagueTaxiConfig) -> LeagueTaxiConfig`: INSERT ... ON CONFLICT (league_id) DO UPDATE SET taxi_slots=EXCLUDED.taxi_slots, taxi_years_eligible=EXCLUDED.taxi_years_eligible, years_pro_cutoff=EXCLUDED.years_pro_cutoff, updated_at=CURRENT_TIMESTAMP. Return the config.

**Lineup Score Persistence**:
- `save_lineup_result(result: LineupResult) -> None`: Serialize `slot_scores` to JSON string, INSERT ... ON CONFLICT (league_id, roster_id) DO UPDATE SET all fields.
- `get_lineup_result(league_id: str, roster_id: int) -> LineupResult | None`: SELECT, deserialize slot_scores_json back to list[LineupSlotScore], return LineupResult or None.

**Hygiene Persistence**:
- `save_hygiene_result(result: HygieneResult) -> None`: Serialize `suggestions` to JSON string, INSERT ... ON CONFLICT (league_id, roster_id) DO UPDATE.
- `get_hygiene_result(league_id: str, roster_id: int) -> HygieneResult | None`: SELECT, deserialize suggestions_json, return HygieneResult or None.

**Taxi/IR Slot Accounting** (per D-18):
- `get_slot_occupancy(league_id: str, roster_id: int) -> dict`: Query rosters table for taxi and reserve (IR) JSON arrays. Return `{"taxi_used": len(taxi), "taxi_total": taxi_config.taxi_slots or 0, "ir_used": len(ir), "ir_total": league_settings ir_slots or 0}`. If no taxi config exists, taxi_total defaults to 0.

All JSON serialization uses `json.dumps(obj, separators=(",", ":"))` and `json.loads()` — same pattern as intelligence_service.py.
