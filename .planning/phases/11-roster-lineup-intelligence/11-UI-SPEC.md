## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline chip padding, badge horizontal pad supplement |
| sm | 8px | Compact row spacing, between-badge gaps, icon-to-label gap |
| md | 16px | Default element spacing, form field spacing, card content row gap |
| lg | 24px | Card section padding (`p-6`), panel-to-panel gap |
| xl | 32px | Layout column gaps, section breaks within league detail page |
| 2xl | 48px | Major section separators (between title-window card and hygiene panel) |
| 3xl | 64px | Page-level vertical rhythm |

Exceptions:
- Touch targets for all interactive controls: minimum 44px height (matches existing button `h-11` = 44px)
- Position slots in lineup grid: 40px min-height for readability at compact density

Source: Existing button/card spacing patterns in `frontend/src/components/ui/` — pre-populated, no override needed.

## Typography

| Role | Size | Weight | Line Height | Font Family |
|------|------|--------|-------------|-------------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 (leading-6) | Inter |
| Label / terminal | 10px | 700 (bold) | 1.2 | Space Grotesk, uppercase, tracking-[0.16em] |
| Heading (card title) | 18px (text-lg) | 700 (bold) | 1.2 (tracking-tight) | Manrope |
| Display (direction / window label) | 24px (text-2xl) | 700 (bold) | 1.1 | Manrope |

Notes:
- The `terminal-label` utility class (10px / weight 700 / uppercase / Space Grotesk / tracking-[0.16em]) is used for all section eyebrows (e.g., "Title Window", "Roster Hygiene", "Taxi / IR Slots").
- Hygiene suggestion reasoning text: 14px (text-sm), weight 400, Inter, line-height 1.5, `text-muted-foreground` — matches secondary description pattern without introducing a new size.
- Numeric values (starter scores, occupancy counts): JetBrains Mono 14px (text-sm), weight 400, uppercase, tracking-[0.16em].

## Color

| Role | CSS Variable | Light Mode | Dark Mode | Usage |
|------|-------------|-----------|-----------|-------|
| Dominant (60%) | `--background` | hsl(210 43% 96%) | hsl(221 69% 8%) | Page background, radial gradient base |
| Secondary (30%) | `--card` / `--secondary` | hsl(0 0% 100%) / hsl(213 42% 92%) | hsl(216 85% 10%) / hsl(214 29% 24%) | Cards (glass-panel), sidebar panels, roster hygiene rows |
| Accent (10%) | `--accent` | hsl(156 100% 81%) | hsl(156 100% 81%) | Reserved list below |
| Primary | `--primary` | hsl(199 100% 49%) | hsl(199 100% 74%) | Active nav buttons, ring focus, primary CTA |
| Destructive | `--destructive` | hsl(4 77% 61%) | hsl(4 77% 70%) | Cut-candidate warning indicators only |

Accent reserved for:
- "Peak Window" label badge background tint (accent/10 bg, accent/20 border, accent-foreground text)
- Consolidation suggestion highlight border when a named counterparty target exists
- No other elements — accent is not used for generic hover states, icons, or progress

Primary (--primary) reserved for:
- Active tab / nav button fill
- Focus ring
- Primary CTA button ("Save Taxi Config")
- Inline "Full analysis" and link affordances

Destructive reserved for:
- Cut-candidate card border/text indicator ("Slot-blocking — cut candidate")
- Error states in taxi config form

Source: `frontend/src/index.css` — pre-populated from existing tokens. No new color tokens required for Phase 11.

## Layout Spec: League Detail Page Additions

Phase 11 adds panels to `frontend/src/routes/league.$leagueId.tsx` in the following order (top to bottom, within the Overview tab):

1. **TitleWindowPanel** — full-width card, immediately below the existing direction header card. Visually distinct from scorecard (separate card, not a 10th dimension).
2. **LineupStrengthCard** — full-width card, below TitleWindowPanel. Position slots in a 2-column or responsive grid.
3. **RosterHygienePanel** — full-width card, below LineupStrengthCard. Sections within card: Consolidation (first), Cut (second), Stash (third), Move to Taxi (fourth).
4. **TaxiIRSlotSummary + TaxiConfigForm** — combined card, at the bottom of the Overview panel stack. Informational slot summary displayed first; config form below (collapsed to "Edit" button when already configured).

Existing panels (ExploitWindowPanel, RisersFallersList, LeaguePickList, DraftOrderRuleForm, SnapshotStatus) remain in their current positions.

## Title-Window Label Visual Contract

Label strings (as defined by discretion — D-05):

| Label | Badge Variant | Color Meaning |
|-------|--------------|---------------|
| `Peak Window` | accent tint — `border-accent/20 bg-accent/10 text-accent-foreground` | Strong green signal — starter ceiling + lineup stability both high |
| `Fading Window` | primary tint — `border-primary/25 bg-primary/12 text-primary` | Ceiling present but declining or fragile |
| `Outside Window` | outline — `border-border/60 bg-transparent text-muted-foreground` | No title contention at current starter level |

These are rendered by the `Badge` component with className overrides for accent vs. default variant when needed.

## Roster Hygiene Section Order and Action Badge Colors

| Section | Badge Label | Badge Variant | Priority |
|---------|-------------|--------------|---------|
| Consolidation | `CONSOLIDATE` | default (primary tint) | 1st — most actionable |
| Cut | `CUT` | destructive tint — `border-destructive/25 bg-destructive/10 text-destructive` | 2nd |
| Stash | `STASH` | secondary (accent tint) | 3rd |
| Move to Taxi | `TAXI` | outline | 4th |

## Interaction Contract

| Interaction | Behavior |
|-------------|---------|
| "Evaluate This Package" link in consolidation row | Navigates to `/trades?leagueId={id}` pre-populated with the suggested assets (same pattern as existing "Evaluate Trade" button) |
| Taxi config save | POST to `/api/leagues/{id}/taxi-config`; on success sets query data + invalidates lineup/hygiene queries; shows "Saving..." during mutation |
| Taxi config cancel | Reverts form to saved state; no confirmation required |
| Edit taxi config | Switches from summary view to form view in-place (same pattern as `DraftOrderRuleForm`) |
| TitleWindowPanel on team screen | Always visible — no expand/collapse; collapsed state not needed |
| RosterHygienePanel sections | All sections open by default; no accordion; scroll if many suggestions |
| LineupStrengthCard position rows | Static display — no interactive selection; click on player name navigates to player context if available (future — not required for Phase 11) |
