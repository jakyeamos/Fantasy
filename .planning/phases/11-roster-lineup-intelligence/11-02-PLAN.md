```python
class LineupEngine:
    def __init__(self, conn: duckdb.DuckDBPyConnection):
        self._conn = conn
        self._scorecard_engine = ScorecardEngine(conn)

    def compute_all(self, league_id: str, all_inputs: dict[int, ScorecardInputs]) -> dict[int, LineupResult]:
        """
        Two-pass lineup computation:
        1. Compute replacement level per position across all rosters (D-01, D-02)
        2. Score each starter slot against its positional replacement level
        3. Compute title-window label from ceiling/stability/depth (D-05, D-06)
        """
```

**Replacement-level logic (D-01, D-02, D-04):**
- For each position P in roster_positions (excluding BN, IR, TAXI):
  - Gather all player IDs starting at position P across all rosters
  - Compute `_value_proxy(inputs, player_id)` for each (reuse the same method from ScorecardEngine — import `ScorecardEngine` and delegate or duplicate the method)
  - Replacement level = `min(values)` for that position
  - If no starters found at position P, fallback to `position_medians.get(P, 5.0)`
- For FLEX and SUPER_FLEX slots (D-03): replacement level = min value across ALL players in any FLEX/SUPER_FLEX slot across all rosters, regardless of their actual position

**Starter scoring:**
- For each starter slot in `inputs.roster_positions` (matching starters list):
  - Get the player's value via `_value_proxy`
  - Get the replacement level for that slot's position
  - `raw_score = max(0, starter_value - replacement_level)`
- Normalize raw_scores within the league using `normalize_within_league`

**Title-window classification (D-05, D-06):**
- `ceiling_score`: For each roster, find the max `comp_ceiling` from player_values table for that roster's starters. Normalize across league. If player_values not available, use max `_value_proxy` of starters as proxy.
- `stability_score`: `1.0 - fragility` from the scorecard (inverse of fragility dimension). Normalize across league.
- `depth_score`: Count bench players above a value threshold (position_medians average). Normalize across league.
- `composite = 0.60 * ceiling + 0.25 * stability + 0.15 * depth`
- Label per thresholds: >= 0.65 "Peak Window", >= 0.35 "Fading Window", else "Outside Window"

Return dict mapping roster_id to LineupResult with all fields populated.

Also implement `_value_proxy` — delegate to ScorecardEngine's method or reimplement the same 3-fallback chain (weekly_fantasy_pts -> adp_ranks -> position_medians).

   # Direction post-adjustment (D-08): nudge contenders with "Outside Window"
   for roster_id, lineup_result in lineup_results.items():
       direction = directions[roster_id]
       if (lineup_result.title_window_label == "Outside Window"

           adjusted_scorecard = scorecards[roster_id].model_copy()
           adjusted_scorecard.fragility = min(1.0, adjusted_scorecard.fragility + TITLE_WINDOW_FRAGILITY_BOOST)

           if adjusted_direction.primary_label != direction.primary_label:

           league_id, roster_id, inputs,
