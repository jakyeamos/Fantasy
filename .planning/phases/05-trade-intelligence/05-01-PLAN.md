**models.py** — create with these exact models (follow Phase 2/4 Pydantic pattern):

```python
from pydantic import BaseModel
from typing import Literal

class TradeAsset(BaseModel):
    asset_type: Literal["player", "pick"]
    player_id: str | None = None
    pick_owner_roster_id: int | None = None  # D-03: specific pick by owner
    pick_year: int | None = None
    pick_round: int | None = None
    projected_slot: str | None = None  # e.g. "1.04"

class ThirdPartyTrade(BaseModel):
    roster_id: int
    sends: list[TradeAsset]
    receives: list[TradeAsset]

class TradeRequest(BaseModel):
    league_id: str
    user_roster_id: int
    counterparty_roster_id: int | None = None  # None for hypothetical
    user_sends: list[TradeAsset]
    user_receives: list[TradeAsset]
    third_party_trades: list[ThirdPartyTrade] | None = None  # D-02
    include_reroutes: bool = False
    include_package: bool = False

class DimensionScore(BaseModel):
    score: float          # 0-100; 50 = neutral
    confidence: Literal["HIGH", "MEDIUM", "LOW"]
    reasoning: str        # one-line human-readable

class StrategicDistinction(BaseModel):
    verdict: Literal["advancing", "negative", "neutral"]
    headline: str         # e.g. "Market fair -- but moves you away from your rebuild"
    explanation: str      # one-sentence elaboration

class RerouteResult(BaseModel):
    reroute_type: Literal["better_target", "better_package"]
    headline: str         # e.g. "Target Ja'Marr Chase instead"
    reasoning: str        # one-line explanation (D-11)
    suggested_assets: list[TradeAsset] | None = None

class PackageOffer(BaseModel):
    label: str            # "Aggressive Open" or "Fair Close"
    send_assets: list[TradeAsset]
    receive_assets: list[TradeAsset]
    reasoning: str        # one-sentence explanation

class PackageBuilderResult(BaseModel):
    aggressive_open: PackageOffer
    fair_close: PackageOffer

class TradeEvaluation(BaseModel):
    market_fairness: DimensionScore
    roster_fit: DimensionScore
    direction_fit: DimensionScore
    timing_quality: DimensionScore
    insulation_delta: DimensionScore
    liquidity_delta: DimensionScore
    manager_exploit_quality: DimensionScore
    strategic_distinction: StrategicDistinction
    reroutes: list[RerouteResult] | None = None
    package: PackageBuilderResult | None = None
```

**Methods to implement (exact SQL queries):**

1. `get_player_values(player_ids: Sequence[str], league_id: str, roster_id: int) -> list[dict]`
   - SELECT from `player_values` table: player_id, comp_insulation, comp_market_liquidity, comp_age_curve, comp_positional_scarcity, comp_short_term, lens_market, lens_insulation, lens_team_fit, lens_direction, lens_production
   - WHERE league_id = ? AND roster_id = ? AND player_id IN (...)
   - Return empty list if player_ids is empty

2. `get_team_direction(league_id: str, roster_id: int) -> dict | None`
   - SELECT from `team_directions`: primary_label, confidence, approved_moves, discouraged_moves
   - WHERE league_id = ? AND roster_id = ?
   - Return dict or None if not found

3. `get_manager_profile(league_id: str, roster_id: int) -> dict | None`
   - SELECT from `manager_profiles`: exploitability_score, exploitation_type_primary, exploitation_type_secondary, evidence_count
   - WHERE league_id = ? AND roster_id = ?
   - Return dict or None if not found

4. `get_pitch_angles(league_id: str, roster_id: int) -> list[dict]`
   - SELECT from `manager_pitch_angles`: archetype_label, what_to_send, what_to_avoid, reasoning
   - WHERE league_id = ? AND roster_id = ?

5. `search_players(league_id: str, q: str, roster_id: int | None = None) -> list[dict]`
   - JOIN players p with rosters r ON p.player_id = ANY(r.players)
   - WHERE r.league_id = ? AND (p.full_name ILIKE '%q%' OR p.position ILIKE '%q%')
   - Optional roster_id filter
   - LIMIT 20 (PLAYER_SEARCH_LIMIT from constants)
   - Return: player_id, full_name, position, roster_id

6. `get_picks_for_league(league_id: str, roster_id: int | None = None) -> list[dict]`
   - SELECT from `traded_picks`: original owner roster_id, current owner_id, season as pick_year, round
   - WHERE league_id = ? with optional owner_id filter
   - ORDER BY season, round
   - Per D-03: returns specific picks by owner, not abstract tiers

7. `get_roster_players(league_id: str, roster_id: int) -> list[dict]`
   - For reroute engine: get all players on a specific roster
   - JOIN players p with rosters r
   - WHERE r.league_id = ? AND r.roster_id = ?
   - Return: player_id, full_name, position

All methods use parameterized queries (no f-string SQL injection). Use `self._conn.execute(sql, params).fetchall()` pattern from existing repos. Convert DuckDB rows to dicts using column names.
