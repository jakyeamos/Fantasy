**7 dimension scoring methods (private):**

1. `_score_market_fairness(sending_values, receiving_values) -> DimensionScore`
   - Sum `lens_market` values for each side
   - Delta normalized: 50 + (received - sent) / max(sent, received, 1) * 50
   - Clamp to 0-100 range
   - Confidence: HIGH if all assets have lens_market, LOW otherwise
   - Reasoning: "You receive {X}% more/less market value than you send"

2. `_score_roster_fit(receiving_values, request, direction) -> DimensionScore`
   - Average `lens_team_fit` of received assets
   - Bonus if received assets fill a positional scarcity (comp_positional_scarcity)
   - Normalized 0-100
   - Reasoning: "Received assets have {high/moderate/low} team fit"

3. `_score_direction_fit(sending_values, receiving_values, direction) -> DimensionScore`
   - Net `lens_direction` delta: sum(received) - sum(sent)
   - Normalize: 50 + delta / max_possible * 50
   - Confidence tied to direction label confidence
   - Reasoning: "This trade {advances/conflicts with/has no impact on} your {direction_label}"

4. `_score_timing_quality(sending_values, receiving_values) -> DimensionScore`
   - Compare `comp_age_curve` and `comp_short_term` between sides
   - Higher score if receiving younger/rising assets, lower if receiving declining
   - Always MEDIUM confidence
   - Reasoning: "You {gain/lose} age curve advantage"

5. `_score_insulation_delta(sending_values, receiving_values) -> DimensionScore`
   - Net `comp_insulation` + `lens_insulation` delta
   - 50 + delta normalized
   - Reasoning: "Net insulation {gain/loss} of {X}%"

6. `_score_liquidity_delta(sending_values, receiving_values) -> DimensionScore`
   - Net `comp_market_liquidity` delta
   - 50 + delta normalized
   - Reasoning: "Received assets are {more/less} liquid than sent assets"

7. `_score_manager_exploit(sending_values, receiving_values, manager_profile) -> DimensionScore`
   - If no manager_profile: score=50, confidence=LOW, reasoning="No manager profile available"
   - If profile exists: score based on how well trade targets documented weakness
   - If evidence_count < MIN_EXPLOIT_EVIDENCE_THRESHOLD: confidence=LOW
   - Reasoning: "This trade {exploits/misses} {exploitation_type} tendencies"

**Strategic distinction method:**
`_compute_strategic_distinction(market_fairness: DimensionScore, direction_fit: DimensionScore, direction_label: str) -> StrategicDistinction`

**routers/trade.py** — Create trade router:

```python
from fastapi import APIRouter, Depends, Query
import duckdb
from fantasy.routers.deps import get_db
from fantasy.trade.trade_engine import TradeEngine
from fantasy.trade.reroute_engine import RerouteEngine
from fantasy.trade.package_builder import PackageBuilder
from fantasy.trade.models import TradeRequest, TradeEvaluation

router = APIRouter()

@router.post("/evaluate", response_model=TradeEvaluation)
async def evaluate_trade(request: TradeRequest, conn = Depends(get_db)):
    engine = TradeEngine(conn)
    evaluation = engine.evaluate(request)
    if request.include_reroutes:
        reroute_engine = RerouteEngine(conn)
        evaluation.reroutes = reroute_engine.generate(request, evaluation)
    if request.include_package:
        builder = PackageBuilder(conn)
        evaluation.package = builder.build(request, evaluation)
    return evaluation

@router.get("/players/search")
async def search_players(
    league_id: str = Query(...),
    q: str = Query(..., min_length=1),
    roster_id: int | None = Query(None),
    conn = Depends(get_db),
):
    from fantasy.trade.trade_repo import TradeRepo
    repo = TradeRepo(conn)
    return repo.search_players(league_id, q, roster_id)

@router.get("/picks/search")
async def search_picks(
    league_id: str = Query(...),
    roster_id: int | None = Query(None),
    conn = Depends(get_db),
):
    from fantasy.trade.trade_repo import TradeRepo
    repo = TradeRepo(conn)
    return repo.get_picks_for_league(league_id, roster_id)
```
