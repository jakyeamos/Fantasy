Create `backend/src/fantasy/rookie_pick/rookie_pick_engine.py`:

The engine is a standalone class (not a subclass of ProfilingEngine) following the RookieEngine pattern. It receives a `duckdb.DuckDBPyConnection`.

Key methods:

**`compute_profile(league_id, roster_id) -> RookiePickProfile`**
1. Load pick trades: query `transactions` table WHERE league_id = ? and `draft_picks` column is non-empty (not null, not '[]', not '{}'). For each transaction, parse `roster_ids` JSON to find if roster_id is a participant. Track received_picks and sent_picks per trade using PICK_VALUE_NORMALIZED.
2. `_compute_pick_premium(pick_trades, roster_id)`: Filter to trades where manager received picks. Compute value delta for each: sum(PICK_VALUE_NORMALIZED.get(r, 0.1) for r in received_picks) - sum(PICK_VALUE_NORMALIZED.get(s, 0.1) for s in sent_picks). A negative delta means overpaid. pick_premium_score = -mean(acquisition_deltas). Returns None when len(pick_trades_received) < MIN_PICK_TRADE_FOR_PREMIUM.
3. Load draft selections: `self._repo.get_draft_selections(league_id, roster_id)` and `self._repo.get_all_league_selections(league_id)`.
4. `_compute_positional_tendency(manager_selections, all_league_selections)`: compute position share per manager vs league average. Position share = count(position) / total. Return delta dict {"QB": ±float, "RB": ±float, "WR": ±float, "TE": ±float}. Use only positions QB/RB/WR/TE; ignore K, DEF, UNKNOWN.
5. `_compute_dominant_archetype(selections)`: For selections with non-None archetype_label, count by label. Find max-count label with count >= 2. Return that label or None.
6. `_compute_archetype_pattern(selections)`: Return Counter of archetype_label for all selections with non-None archetype_label.
7. Compute `evidence_count = len(pick_trades) + len(manager_selections)`. `show_draft_picks_tab = evidence_count >= MIN_ROOKIE_PICK_EVIDENCE`.
8. Build `draft_selection_history`: return manager_selections list directly (already sorted by season DESC, pick_slot ASC from repo).

**`_map_archetype_label(player_id) -> str | None`**
Query `players` table for position and metadata blob. Call `RookieEngine._assign_archetype()` passing a synthetic player dict `{"position": row.position, "metadata": json.loads(row.metadata or "{}"), "avg_fantasy_points": 0.0}`. Catch any exception and return None. This method is called when upserting draft selections.

**`enrich_selection_archetypes(league_id) -> int`**
For all draft_pick_selections rows in this league where archetype_label IS NULL, compute archetype via `_map_archetype_label(player_id)` and update via `self._repo.upsert_draft_selection(updated_sel)`. Return count of rows enriched.

**`compute_tendency_warnings(league_id) -> list[TendencyWarning]`**
For each roster_id in the league (from manager_rookie_pick_profiles table), if their positional_tendency shows any position deviation > 0.15 (15 percentage points above league avg), emit a TendencyWarning with:
- `warning_type = "manager_tendency"`
- `title = f"{manager_name} targets {position} early"` (get manager_name from rosters table: `SELECT owner_display_name FROM rosters WHERE league_id = ? AND roster_id = ?`)
- `description = f"{manager_name} has targeted {position} in {N} of {total} draft selections in this league."`
- `affected_players = []`

Only emit warnings for managers with show_draft_picks_tab = True or pick_trade_evidence >= MIN_PICK_TRADE_FOR_PREMIUM (sufficient evidence to be shown in draft room per D-17 — but only if evidence clears minimum).

```python
@router.post("/leagues/{league_id}/ingest/draft-picks")
async def ingest_draft_picks(
    league_id: str,
    conn: duckdb.DuckDBPyConnection = Depends(get_write_db_conn),
) -> dict[str, Any]:
    """On-demand draft pick ingestion. Fetches all drafts for league, ingests pick selections.
    NOT part of the standard ingest flow (D-11). Call manually after a draft completes.
    Returns: {ingested: N, leagues_fetched: league_id}
    """
    async with SleeperClient() as client:
        drafts = await client.fetch_drafts(league_id)
        rp_repo = RookiePickDataRepo(conn)
        rp_engine = RookiePickProfileEngine(conn)
        total_ingested = 0
        for draft in drafts:
            draft_id = draft.get("draft_id") or draft.get("draft_id")
            if not draft_id:
                continue
            draft_type = draft.get("type", "rookie")
            mapped_type = "startup" if draft_type == "snake" else "rookie"
            season = int(draft.get("season", 2026))
            raw_picks = await client.fetch_draft_picks(draft_id)
            selections = SleeperMapper.map_draft_pick_selections(
                raw_picks, league_id, str(draft_id), season, mapped_type
            )
            for sel in selections:
                rp_repo.upsert_draft_selection(sel)
                total_ingested += 1
        # After ingestion, enrich archetype labels for this league
        rp_engine.enrich_selection_archetypes(league_id)
    return {"ingested": total_ingested, "league_id": league_id}
```
