## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline chip padding, factor badge gaps |
| sm | 8px | Compact element spacing, badge internal padding |
| md | 16px | Default element spacing, card inner content gaps |
| lg | 24px | Section padding, card header/content padding |
| xl | 32px | Layout gaps between major panels |
| 2xl | 48px | Major section breaks between recommendation card groups |
| 3xl | 64px | Page-level spacing |

Source: Derived from established project patterns (card.tsx uses `p-6` = 24px, button.tsx uses `px-4` = 16px, gap-3 = 12px used throughout). Standard 8-point grid applies; 12px (gap-3) is a permitted sub-token inherited from project convention.

Exceptions:
- 44px touch target minimum applies to all interactive CTA buttons (maintained from existing `h-11` button default).
- 40px icon containers (size-10) used for panel status icons — established pattern in `FormatWarningBanner`, `LeagueCard`.

## Typography

| Role | Size | Weight | Line Height | Font Family |
|------|------|--------|-------------|-------------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 | Inter (--font-body) |
| Label (terminal) | 10px, uppercase, tracking-[0.16em] | 700 (bold) | 1.4 | Space Grotesk (--font-label) |
| Sub-label / meta | 12px (text-xs) | 400 (regular) | 1.5 | Inter (--font-body) |
| Heading (card title) | 18px (text-lg) | 700 (bold) | 1.2 | Manrope (--font-headline) |
| Display (large card stat/label) | 24px (text-2xl) | 800 (extrabold) | 1.2 | Manrope (--font-headline) |

Source: Derived from `index.css`, `card.tsx` (`text-lg font-bold font-headline`), `LeagueCard.tsx` (`text-xl`), `TitleWindowPanel.tsx` (`text-2xl font-headline font-extrabold`), `button.tsx` (`text-[11px]` uppercase).

Notes:
- `terminal-label` class encapsulates 10px / weight-700 / uppercase / tracking-[0.16em] / Space Grotesk — this class is used for all section eyebrow labels and is required for Phase 17 recommendation card section headers (e.g., "Recommendation", "Priority", "Market Gap").
- Recommendation card headlines (the `headline` field of `RecommendationCard`) render at 18px Manrope weight-700.
- `why_summary` and `explanation` fields render at 14px Inter weight-400 line-height 1.5.
- Confidence labels render at 10px uppercase terminal-label.
- Market gap classification labels (buy low / sell high / hold) render at 10px uppercase terminal-label in the appropriate semantic color.
- `supporting_factors[]` factor names render at 12px Space Grotesk weight-600.
- Priority rank numeral renders at 12px JetBrains Mono uppercase.

## Color

| Role | CSS Variable | Light Value | Dark Value | Usage |
|------|-------------|-------------|------------|-------|
| Dominant (60%) | --background | hsl(210 43% 96%) | hsl(221 69% 8%) | Page background, gradient surface |
| Secondary (30%) | --card | hsl(0 0% 100%) | hsl(216 85% 10%) | Cards, panels, recommendation card backgrounds |
| Accent (10%) | --accent | hsl(156 100% 81%) | hsl(156 100% 81%) | Reserved elements (see below) |
| Primary | --primary | hsl(199 100% 49%) | hsl(199 100% 74%) | CTAs, links, active states, priority indicators |
| Destructive | --destructive | hsl(4 77% 61%) | hsl(4 77% 70%) | Error states only |
| Muted | --muted-foreground | hsl(219 16% 38%) | hsl(216 17% 65%) | Supporting text, labels, meta copy |

Source: `frontend/src/index.css` — all values pre-declared.

**Accent (hsl(156 100% 81%)) reserved exclusively for:**
- "Peak Window" title window badge (established in TitleWindowPanel)
- Positive market gap signals: buy-low classification badge background/text
- "Hold despite weak market" — positive conclusion badge

**Primary (hsl(199 100% 49%) / hsl(199 100% 74%)) reserved for:**
- Primary CTA buttons (`Button variant="default"`)
- Recommendation card border highlight when verdict is "advancing" or gap is actionable
- Priority rank indicator (numeric pill)
- Model-vs-market gap badge when gap is significant (buy-low / sell-high)

**Semantic colors for recommendation card supporting factors:**
- Positive direction factor: `text-green-500` / `bg-green-50` (established in RookiePlayerCard risk badges)
- Negative direction factor: `text-red-400` / `bg-red-50`
- Neutral direction factor: `text-muted-foreground` / `bg-card/50`

**Market gap classification colors:**
- `buy_low`: primary/accent treatment — `border-primary/25 bg-primary/10 text-primary`
- `sell_high`: amber treatment — `border-amber-400/25 bg-amber-400/10 text-amber-600 dark:text-amber-300`
- `hold_despite_weak_market`: accent treatment — `border-accent/20 bg-accent/10 text-accent-foreground`
- `ignore_false_discount`: muted treatment — `border-border/40 bg-card/45 text-muted-foreground`
- `market_right_model_cautious`: muted treatment — `border-border/40 bg-card/45 text-muted-foreground`
- `league_specific_opportunity`: primary treatment — `border-primary/25 bg-primary/10 text-primary`

## Interaction Contracts

### Recommendation Card

- **Default state:** Card renders with all fields visible. No expand/collapse. Supporting factors are always visible (maximum 4 visible, remainder hidden under "Show N more" ghost button).
- **CTA button:** Uses `Button variant="default" size="sm"` with `cta_label` as the button text. `cta_destination` is resolved by the frontend to a route path. The button navigates or scrolls to the relevant module surface.
- **Confidence LOW:** Renders the LOW badge prominently above the headline. Does not suppress the card — LOW confidence cards display with an additional muted annotation: "Limited evidence. Treat as directional, not conclusive."
- **Hover:** No hover state change on the card itself (consistent with existing Card pattern). CTA button follows existing Button hover behavior.
- **Loading state:** Full card skeleton using Skeleton primitive — 3 rows at heights h-4, h-6, h-4 matching approximate text heights.
- **Empty recommendation list:** Render the empty state inline (see Copywriting).

### Market Gap Panel

- **Default state:** Compact inline panel, not expandable. Shows model rank, market rank, gap direction icon (TrendingUp / TrendingDown / Minus from lucide-react), MarketGapBadge.
- **"Hold despite weak market"** renders with accent color treatment, same visual weight as a buy-low signal.
- No interaction — read-only display surface.

### Supporting Factors

- Positive factors: left border `border-l-2 border-l-green-500`, icon `TrendingUp` in green.
- Negative factors: left border `border-l-2 border-l-red-400`, icon `TrendingDown` in red.
- Neutral factors: left border `border-l-2 border-l-border/40`, icon `Minus` in muted.
- Magnitude bar: thin horizontal bar (h-1 rounded-full bg-border/30) with filled portion in the factor's direction color, proportional to magnitude value.

### Player Context Flag

- Displayed inline within `supporting_factors[]` on the card (flags are factors, not a separate UI panel — per D-13).
- Flag type renders as terminal-label in muted-foreground.
- Expiry not shown to user (D-09: stabilization is silent; flag visibility tracks the flag's active state only).

### Anti-Overreaction Layer

- No UI annotation for the stabilization prior (D-09 — silent behavior).
- The stabilized recommendation is the only thing shown. No "insulation prior applied" badge or annotation anywhere.
