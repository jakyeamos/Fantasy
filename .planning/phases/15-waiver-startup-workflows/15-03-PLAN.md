```python
def detect_startup_mode(draft_status: str) -> bool:
    """Returns True when Sleeper draft status indicates an active startup."""
    return draft_status in ("pre_draft", "drafting")

def assign_build_template(direction_label: str) -> Literal["win_now", "balanced", "rebuild"]:
    """Maps direction label to startup build template."""
    return BUILD_TEMPLATE_MAP.get(direction_label, "balanced")
```

Build template hint strings (one per template, return as `build_template_hint`):
- `"win_now"`: `"True Contender build: prioritize proven starters, trade picks for veterans, avoid late-round upside."`
- `"balanced"`: `"Balanced build: hold first-round picks, trade second-round picks for ascending 24-27 year-old starters."`
- `"rebuild"`: `"Rebuild build: accumulate all picks, target 21-24 year-old upside, avoid win-now assets."`

Trade-up/down heuristics — apply per pick in the pick valuation list:
- Trade **up**: `slots_to_next_tier_break <= 3` AND `top_player_in_next_tier.score - next_available_at_current_slot.score >= 20`
- Trade **down**: count of players in `same_tier_remaining_in_draft >= 3` (meaning equivalents are available if you slip)

`StartupEngine.compute_context()` must:
1. Query draft status from DB (use existing SleeperClient data in `drafts` table if available, else fallback to `"unknown"`)
2. Get current direction label from `team_directions` table for the given roster_id
3. Assign build template and hint from the helpers above
4. Build pick valuations list from existing `pick_values` table (use `demand_adjusted_value` as the score, convert to `StartupPickValuation` items, apply trade-up/down heuristics)
5. Set `startup_mode_available = detect_startup_mode(draft_status)`
6. Return `StartupContext` Pydantic model

For the unit tests, test the standalone functions `detect_startup_mode` and `assign_build_template` directly (no DB needed). For trade heuristic tests, construct synthetic `StartupPickValuation`-shaped inputs and test the heuristic logic function in isolation.
