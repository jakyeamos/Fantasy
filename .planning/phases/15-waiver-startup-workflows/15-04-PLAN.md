Implement `compute_orphan_composite` as a standalone function for direct testability:

```python
def compute_orphan_composite(
    age_curve_score: float,
    pick_capital_score: float,
    dead_spots_score: float,
    lineup_viability_score: float,
    liquidation_score: float,
) -> float:
    """Weighted composite of 5 orphan intake dimensions. Always returns 0-100."""
    raw = (
        age_curve_score * ORPHAN_WEIGHT_AGE_CURVE
        + pick_capital_score * ORPHAN_WEIGHT_PICK_CAPITAL
        + dead_spots_score * ORPHAN_WEIGHT_DEAD_SPOTS
        + lineup_viability_score * ORPHAN_WEIGHT_LINEUP
        + liquidation_score * ORPHAN_WEIGHT_LIQUIDATION
    )
    return max(0.0, min(100.0, raw))
```

Composite label assignment:
```python
def get_composite_label(composite: float) -> str:
    if composite <= ORPHAN_DISTRESSED_MAX:
        return "Distressed"
    if composite <= ORPHAN_REBUILDER_MAX:
        return "Rebuilder"
    if composite <= ORPHAN_BALANCED_MAX:
        return "Balanced"
    return "Ready to Compete"
```

5-dimension scoring logic for `OrphanEngine.compute_intake()`:

**age_curve_score:** Query `player_values` for roster players. Get each player's `comp_age_curve` component (0-100). Score = percentage of starting-lineup players with `comp_age_curve >= 50`. Multiply by 100. Young rosters score high.

**pick_capital_score:** Query `pick_values` for `demand_adjusted_value` across all held picks. Normalize against league median sum (from `pick_values` table). Cap at 100. If no picks exist, score = 0.

**dead_spots_score:** Query `hygiene_suggestions` JSON for roster_id. Count players with action = `"cut"`. Score = `max(0, 100 - (cut_count / roster_size * 100))`. Fewer dead spots = higher score.

**lineup_viability_score:** Query `lineup_scores` for `total_lineup_score`. Normalize against league median `total_lineup_score`. Cap at 100.

**liquidation_score:** Query `player_values` for players with `lens_market > 60`. Count as "liquid assets." Score = `min(100, liquid_count / max(1, roster_size) * 200)` (generous since even 50% liquid is good).

Action plan generation (`generate_action_plan()`):
1. Build items from dimension scores below threshold
2. Add top 3 waiver add targets from `WaiverEngine.compute_recommendations()` as `"add"` items with urgency `"this_week"`
3. Add top 3 cut players from hygiene suggestions as `"drop"` items
4. Add top approved moves from `team_directions.approved_moves` as `"trade"` items
5. Sort: urgency order `["this_week", "30_days", "offseason"]` then by priority_rank
6. Assign priority_rank 1..N after sorting

Unit tests use in-memory `compute_orphan_composite()` and list-sorting logic — no DB needed.
