- A recompute always re-runs all three engines in sequence.

API endpoints to create:
- `POST /intelligence/compute/{league_id}` — trigger full pipeline for a league; returns {"status": "ok", "teams_computed": N}
- `GET /intelligence/scorecard/{league_id}/{roster_id}` — read from team_scorecards table; 404 if not yet computed
- `GET /intelligence/direction/{league_id}/{roster_id}` — read from team_directions table; deserialize JSON columns; include ranked_moves (computed live from DirectionEngine.rank_moves())
- `GET /intelligence/player-value/{league_id}/{roster_id}/{player_id}` — read from player_values table; 404 if not found

Error handling: all endpoints return `{"detail": "Not computed yet — run POST /intelligence/compute/{league_id} first"}` with 404 if the requested row doesn't exist in the output table.
