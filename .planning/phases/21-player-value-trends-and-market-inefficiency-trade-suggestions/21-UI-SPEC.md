## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline chip padding, ownership symbol gap |
| sm | 8px | Compact element spacing, card row separation |
| md | 16px | Default element spacing, card inner content gaps |
| lg | 24px | Section padding, card header/content padding |
| xl | 32px | Layout gaps between opportunity feed and supporting sections |
| 2xl | 48px | Major section breaks on `/opportunities` route |
| 3xl | 64px | Page-level spacing |

Source: Inherited from established project patterns (card.tsx `p-6` = 24px, `gap-3` = 12px, button.tsx `px-4` = 16px). Standard 8-point scale applies; 12px (`gap-3`) is a permitted sub-token inherited from prior phases.

Exceptions:
- 44px minimum touch target applies to all interactive CTA buttons (matches existing `h-11` button default, confirmed in `Button` `size="default"`).
- Opportunity card ownership symbol row uses 12px gap between symbol and league name — consistent with `gap-3` sub-token established across prior phases.

## Typography

| Role | Size | Weight | Line Height | Font Family |
|------|------|--------|-------------|-------------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 | Inter (`--font-body`) |
| Label (terminal) | 12px (text-xs), uppercase, tracking-[0.16em] | 700 (bold) | 1.4 | Space Grotesk (`--font-label`) via `.terminal-label` class |
| Heading (card title) | 18px (text-lg) | 700 (bold) | 1.2 | Manrope (`--font-headline`) |
| Display (feed header / page anchor) | 24px (text-2xl) | 700 (bold) | 1.2 | Manrope (`--font-headline`) |

Source: Inherited verbatim from Phase 17 UI-SPEC — confirmed correct by reading `index.css`, `card.tsx`, `button.tsx`, and `RookiePlayerCard.tsx`.

Notes:
- Declared scale: 12px / 14px / 18px / 24px. Exactly 4 sizes. Compliant.
- Declared weights: 400 (regular) / 700 (bold). Exactly 2 weights. Compliant.
- `.terminal-label` (12px / 700 / uppercase / tracking-[0.16em] / Space Grotesk) is used for all opportunity card section eyebrows: "TREND SIGNAL", "SUGGESTED ACTION", "SIMILAR PLAYERS", "OWNED IN", and the conflict label "SIGNAL CONFLICT".
- `trend_label` ("WILL RISE" / "WILL MAINTAIN" / "WILL FALL") renders as `.terminal-label` treatment inside a color-coded badge (see Color section).
- Player name on opportunity card renders at 14px Inter weight-700 (using `font-bold`).
- `why_summary` / similarity `context` strings render at 14px Inter weight-400 line-height 1.5.
- Impact score renders at 12px JetBrains Mono (`font-mono`) — no uppercase, default tracking. Differentiates from label roles by font family alone.
- Conflict explanation (D-10) renders at 14px Inter weight-400, inside a bordered container — same body treatment as `supporting_factors` explanation text in Phase 17.
- Calendar-trigger rank escalation note renders as `.terminal-label` in `text-primary` — same as "High Opportunity" in `ExploitWindowPanel`.

## Color

| Role | CSS Variable | Light Value | Dark Value | Usage |
|------|-------------|-------------|------------|-------|
| Dominant (60%) | `--background` | hsl(210 43% 96%) | hsl(221 69% 8%) | Page background, gradient surface |

| Accent (10%) | `--accent` | hsl(156 100% 81%) | hsl(156 100% 81%) | Reserved elements (see below) |

| Destructive | `--destructive` | hsl(4 77% 61%) | hsl(4 77% 70%) | "Sell" suggested action badge treatment |
| Muted | `--muted-foreground` | hsl(219 16% 38%) | hsl(216 17% 65%) | Supporting text, meta copy, similarity score, confidence indicator |

Source: `frontend/src/index.css` — all values pre-declared. No new color tokens introduced.

**Accent (hsl(156 100% 81%)) reserved exclusively for:**
- "Hold" / "WILL MAINTAIN" trend badge treatment — signals a positive-but-neutral conclusion in the same vein as "Hold despite weak market" from Phase 17.
- Conflict resolution badge when Phase 17 and Phase 21 signals agree directionally despite surface tension.

**Primary (hsl(199 100% 49%) / hsl(199 100% 74%)) reserved for:**
- "Buy" suggested action badge: `border-primary/25 bg-primary/10 text-primary`
- Ownership symbol icon (indicates user holds this player in a league)
- Calendar-trigger escalation label (`.terminal-label text-primary`) on opportunity cards with imminent rank change
- Trend badge for "WILL RISE": `border-primary/25 bg-primary/10 text-primary`

**Destructive reserved for:**
- "Sell" suggested action badge: `border-destructive/25 bg-destructive/10 text-destructive`
- Trend badge for "WILL FALL": `border-destructive/25 bg-destructive/10 text-destructive`

**Semantic colors for trend badges:**
- `will_rise`: primary treatment — `border-primary/25 bg-primary/10 text-primary`
- `will_maintain`: accent treatment — `border-accent/20 bg-accent/10 text-accent-foreground`
- `will_fall`: destructive treatment — `border-destructive/25 bg-destructive/10 text-destructive`

**Suggested action badge colors:**
- `buy`: primary treatment — `border-primary/25 bg-primary/10 text-primary`
- `sell`: destructive treatment — `border-destructive/25 bg-destructive/10 text-destructive`
- `hold`: accent treatment — `border-accent/20 bg-accent/10 text-accent-foreground`

**Conflict signal treatment (D-10):**
- Conflict container: `rounded-xl border border-amber-400/30 bg-amber-400/8 p-4` — amber is the established "caution / tension" color from the existing codebase (`TimingBadge`, risk states).
- Conflict label `.terminal-label`: `text-amber-600 dark:text-amber-300`
- Conflict body text: `text-sm text-foreground` (not muted — this is first-class content per D-10 specifics).

**Similarity score color:**
- Similarity score renders as `font-mono text-xs text-muted-foreground` — same treatment as delta values in `RisersFallersList`.

## Visuals

Primary visual anchor for Phase 21: the opportunity feed's first card (highest impact score). The feed is a single ordered list — no tabs, no split buy/sell panes (D-08). Each card is visually distinguished from a metric `Card` by its left-side trend badge (colored per trend label) and the suggested action badge in the top-right corner.

The feed route (`/opportunities`) opens with a display-scale section header: "Opportunity Feed" in Manrope 24px/700 with a `.terminal-label` subtitle "Ranked by impact — gap magnitude × projection confidence." This is the page's visual orientation anchor.

Conflict explanations (D-10) are visually elevated: amber container with full-weight body text, placed immediately below the primary trend section in a card. Not a footnote. Width matches the card's content column.

Calendar-trigger escalation (D-15) is surfaced as a `.terminal-label text-primary` inline annotation above the player name when a rank change is imminent: e.g. "COMBINE WEEK — RANK ESCALATED".

## Screen Contracts

### Screen 1: Opportunity Feed (`/opportunities`)

**Route:** New route `src/routes/opportunities.tsx`

**Layout (top to bottom):**

Row 1 — Page header:
- `font-headline text-2xl font-bold tracking-tight` "Opportunity Feed"
- `.terminal-label text-muted-foreground` sub-label: "RANKED BY IMPACT — GAP MAGNITUDE × PROJECTION CONFIDENCE"
- No filter controls in Phase 21. Sorted by impact score descending. Sort is fixed.

Row 2 — Feed list:
- `OpportunityCardList` spanning full width
- `space-y-4` between cards (16px)
- No grid — single column stack

**Navigation entry point:** Dashboard index route links to `/opportunities` via the existing Cross-League Exposure card footer (add `<Link to="/opportunities">` using `buttonClasses({ variant: "outline" })`) plus a top-section stat tile: "Opportunities" count tile using the same `icon + value + helper` pattern as "Clear Reads" and "Exploit Windows".

**Opportunity Card anatomy (within `OpportunityCard`):**

Top row — `flex items-start justify-between gap-3`:
- Left: `CalendarEscalationLabel` (conditional, renders above player name when active)
- Left: player name `text-sm font-bold text-foreground` + `Badge variant="outline"` position tag
- Left: `OwnershipSymbol` inline after position tag
- Right: `SuggestedActionBadge`

Second row — `flex items-center gap-3 mt-2`:
- `TrendBadge` (trend label)
- ADP gap: `font-mono text-xs text-muted-foreground` — e.g. "ADP Gap: +18"
- Impact score: `.terminal-label text-muted-foreground` — e.g. "IMPACT 74"
- `ConfidenceIndicator`

Body — `mt-3 text-sm text-muted-foreground leading-relaxed`:
- `why_summary` explanation text

Conflict section — `mt-3` conditional:
- `ConflictExplanationPanel` (amber container, full-weight body text)

Similar players section — `mt-3`:
- `SimilarPlayersSection` (collapsed by default)

Card chrome: `rounded-xl border border-border/60 bg-card/75 p-5` — matches existing `Card` glass-panel base. No left accent stripe (unlike Phase 17 `RecommendationCard`) — opportunity cards are feed items, not calls-to-action. They are distinguished by the `TrendBadge` and `SuggestedActionBadge` instead.

## Interaction Contracts

### Opportunity Card

- **Default state:** Card fully visible. `SimilarPlayersSection` collapsed. `ConflictExplanationPanel` visible if conflict exists — never collapsed (D-10 first-class content).
- **No hover state change** on the card body (consistent with existing `Card` pattern — no lift, no border change).
- **`SimilarPlayersSection` expand/collapse:** Chevron toggle (`ChevronDown` / `ChevronUp` from lucide-react). Transition: `transition: 160ms ease` (inherited global rule). Collapsed: shows `.terminal-label` "SIMILAR PLAYERS ({N})" with chevron. Expanded: shows full list.
- **Loading state:** Full card skeleton — `Skeleton h-6 w-32` (player name), `Skeleton h-4 w-48 mt-2` (trend + ADP row), `Skeleton h-12 w-full mt-3` (body text). Repeat for 5 skeleton cards.
- **No interactive CTA on opportunity card itself.** The card is read-only. If Phase 17 `RecommendationCard` links exist downstream (e.g. "Evaluate This Trade"), they are accessed by navigating to the relevant screen — not from the opportunity card directly.

### Phase 17 Integration (Trend Factors in Recommendation Cards)

- Trend `supporting_factors[]` entries render inside existing `SupportingFactorRow` — no new interaction. Direction icon: `TrendingUp` for `will_rise` (green), `TrendingDown` for `will_fall` (red), `Minus` for `will_maintain` (muted). Factor name: "Value Trend". Magnitude bar: proportional to trend confidence × gap magnitude.
- Anti-overreaction weakening (D-11) is silent — no UI badge. The stabilized output is the only thing shown. Same principle as Phase 17 D-09.
- Conflict inline in Phase 17 recommendation card (D-10): if trend and gap classification disagree, the conflict explanation appears as the last entry in `supporting_factors[]` with `direction: "neutral"` treatment and the explanation text covering both signals.

### Confidence LOW on Opportunity Cards

- LOW confidence renders `ConfidenceIndicator` with `Badge variant="outline"` and muted styling.
- Card is not suppressed (per D-14: gap magnitude is the primary gate; confidence modulates the flag, not the visibility).
- LOW confidence annotation below the body: `text-xs text-muted-foreground italic` — "Limited projection confidence. Treat as directional."

### Calendar Escalation Label

- Renders only when the backend marks a card as calendar-escalated (D-15).
- No interaction — display only.
- Lucide icon: `CalendarClock size-3` inline before the label text (or omit icon if `CalendarClock` is not available — text alone is sufficient).
