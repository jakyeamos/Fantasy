1. `GET /picks/{league_id}` — Batch fetch all pick values for a league.
   - Instantiate PickEngine with DuckDB connection from deps.
   - Call `repo.get_all_picks(league_id)` to get all future picks.
   - Call `engine.compute_batch(picks, league_id)` to compute values.
   - Return list of PickValue as JSON. Each PickValue includes timing_label, timing_reasoning, all value layers (base, timed, league_adjusted, demand_adjusted), expected_draft_slot, computed_at.
   - If no picks found, return empty list (not 404).

2. `GET /picks/{league_id}/{owner_roster_id}/{year}/{round}` — Single pick value.
   - Build TradedPick from path params.
   - Call `engine.compute(pick, league_id)`.
   - Return single PickValue.
   - 404 if pick not found in picks table.

3. `POST /picks/{league_id}/recompute` — Trigger batch recompute.
   - Fetch all picks, compute batch, persist via `repo.save_pick_values(values)`.
   - Return {"recomputed": N, "league_id": league_id}.
