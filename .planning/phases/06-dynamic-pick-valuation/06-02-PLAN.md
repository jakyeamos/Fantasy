**Helper functions (module-level, independently testable):**

1. `expected_draft_slot(win_pct: float, remaining_games: int, league_size: int) -> float`
   - Guard remaining_games == 0: return rank from win_pct directly (Pitfall 1)
   - Regression formula: regressed_win_pct = (win_pct * games_played + 0.5 * remaining_games) / TOTAL_SEASON_GAMES
   - Convert to slot: lower win_pct = lower slot number (higher pick). Sort-rank approach: slot = round((1 - regressed_win_pct) * (league_size - 1)) + 1, clamped to [1, league_size]

2. `slot_to_base_value(slot: float, league_size: int) -> float`
   - Power decay: FIRST_ROUND_BASE_VALUE * (1 / slot) ** SLOT_VALUE_DECAY_EXPONENT
   - For multi-round: slot can exceed league_size (slot 13 = 2.01 in a 12-team league)

3. `compute_rebuilder_adjustment(rebuilder_ratio: float) -> float`
   - Per research formula: delta from NEUTRAL_REBUILDER_RATIO, scaled by MAX_REBUILDER_PREMIUM

4. `sigmoid(x: float, k: float, center: float) -> float`
   - Standard sigmoid: 1 / (1 + exp(-k * (x - center)))

5. `compute_timing_rec(slot, standings: TeamStandingsRow, month: int) -> TimingLabel`
   - Decision tree per research: draft_in_progress -> USE_ON_THE_CLOCK, peak + early slot -> SELL_NOW, trending down mid-season -> SELL_NOW, else HOLD

6. `compute_timing_reasoning(label: TimingLabel, standings: TeamStandingsRow, month: int) -> str`
   - Template lookup + format per research TIMING_REASONING_TEMPLATES
