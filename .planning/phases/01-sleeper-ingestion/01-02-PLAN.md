Module-level `SLEEPER_TO_NFLDATA_MAP: dict[str, str]` mapping Sleeper scoring keys to nfl_data_py column names (see RESEARCH.md Pattern 5 and Code Examples for the seed mapping). This dict is the central translation layer — unmapped keys are logged, not silently ignored.

```python
def compute_fantasy_points(stats_row: dict, scoring_settings: dict[str, float], position: str) -> float:
    total = 0.0
    unmapped_keys = []
    for sleeper_key, points_per_unit in scoring_settings.items():
        nfldata_col = SLEEPER_TO_NFLDATA_MAP.get(sleeper_key)
        if nfldata_col is None:
            unmapped_keys.append(sleeper_key)
            continue
        stat_value = stats_row.get(nfldata_col, 0.0) or 0.0
        if sleeper_key == "bonus_rec_te" and position != "TE":
            continue
        total += stat_value * points_per_unit
    return round(total, 2)
```

`unmapped_keys` should be returned alongside the total (or stored on the instance for gap surfacing). Return type can be `tuple[float, list[str]]` — the list is consumed by the gap_detector in Plan 05.

- `upsert_weekly_stats(conn, df: pl.DataFrame) -> None`: inserts using DuckDB's ability to query polars DataFrames directly: `conn.execute("INSERT OR REPLACE INTO player_stats_weekly SELECT * FROM df")`
