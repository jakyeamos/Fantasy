    Class `ProfilingEngine` with `__init__(self, conn: duckdb.DuckDBPyConnection)`:

    Private methods:
    - `_load_trades(self, league_id: str, roster_id: int) -> list[dict]`: Query `transactions WHERE league_id = ? AND type = 'trade'` and filter to trades involving this roster_id. CRITICAL: filter `type = 'trade'` per RESEARCH.md pitfall #1.
    - `_parse_trade_sides(self, transaction: dict, roster_id: int) -> tuple[list[str], list[str]]`: Parse `adds` and `drops` JSON. `adds[str(roster_id)]` = received player_ids, `drops[str(roster_id)]` = sent player_ids. Handle missing keys gracefully.
    - `_load_adp_values(self, player_ids: list[str]) -> dict[str, float]`: Query `player_adp_baseline` for ADP ranks. Convert to normalized 0-1 score: `value = 1.0 - (adp_rank / max_adp_rank)` where max_adp_rank is the maximum ADP rank in the table. For missing players, use `ADP_FALLBACK_BY_POSITION` looked up via `players.position`.
    - `_compute_value_delta(self, received_ids: list[str], sent_ids: list[str], pick_rounds: list[int], adp_map: dict) -> float`: Sum received values - sum sent values. Draft picks use `PICK_VALUE_NORMALIZED` by round number.
    - `_load_direction(self, league_id: str, roster_id: int) -> Optional[str]`: Query `team_directions` for `primary_label`. Return None if no row exists (Phase 2 not run — per RESEARCH.md pitfall #6).
    - `_classify_exploitation(self, trades: list[dict], direction: Optional[str], adp_map: dict) -> ExploitationClassification`:
      - Compute per-type evidence counts:
        - value_loss: count trades with negative delta; primary if win_rate < 0.40
        - timing_error: compare trade timestamps to performance windows (simplified: flag trades where player's ADP delta changed >20% within 4 weeks of trade)
        - directional_incoherence: if direction is not None, check if trade direction contradicts label (rebuilder selling picks, contender selling starters). Skip if direction is None.
        - archetype_overpay: group received players by position; if avg_delta < -0.10 for a position across 3+ trades, flag
      - Primary type = type with highest evidence count
      - Secondary type = next highest if evidence >= SECONDARY_TYPE_THRESHOLD_RATIO * primary_evidence
      - Build evidence_strings using the exact aggregate formats from D-11: "Lost value on {n} of {total} trades", "Sold during value trough on {n} of {total} trades", "{n} trades contradict {direction_label} direction", "Overpaid for {position} in {n} of {n_applicable} trades"
    - `_compute_score(self, trades: list[dict], exploitation: ExploitationClassification) -> float`:
      - Weighted sum of per-type signal strengths using EXPLOITATION_TYPE_WEIGHTS
      - Scale to 0-100 range
      - Higher score = more exploitable
    - `_compute_pitch_angles(self, exploitation: ExploitationClassification, direction: Optional[str]) -> list[PitchAngle]`:
      - Look up applicable archetypes from PITCH_ARCHETYPES based on exploitation.primary_type + direction
      - Return 2-3 PitchAngle objects ranked by relevance (rank=1 is the top preview angle per D-14)

    Public method:
    - `compute_profile(self, league_id: str, roster_id: int) -> ManagerProfile`:
      - Load trades, direction, compute ADP map for all traded players
      - Compute exploitation classification, score, pitch angles
      - Set `low_confidence = evidence_count < MIN_TRADE_EVIDENCE_THRESHOLD` (per D-15, D-16)
      - Build roster_summary from rosters + team_directions (direction_label, positional_needs)
      - Build aggregate_trade_stats: {total_trades, win_rate, avg_delta}
      - Return ManagerProfile

    - `compute_all_profiles(self, league_id: str) -> list[ManagerProfile]`:
      - Get all roster_ids from `rosters WHERE league_id = ?`
      - Call compute_profile for each
      - Return list
